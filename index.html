Google Drive sync Automatic sync between all your devices via a private file in your own Google Drive. No server of ours involved — this app talks directly to Google.

One-time setup: create a free Google OAuth Client ID (see the setup guide provided separately), then paste it below.

Not connected

This device's name Used to label backups and sync files so you can tell which device they came from — e.g. "Amit's Phone" or "Office PC". Set this separately on each device.

Backups Point-in-time snapshots, separate from the live sync file, so a mistake that gets synced doesn't erase your only backup too.

A dated snapshot is saved automatically to your Google Drive every time you sync. Keeps roughly the last 7 syncs plus up to 4 older weekly-spaced snapshots, so you have real history to fall back on — not just the live copy.

Bank transaction import Bring in transactions from a CSV exported by your bank's online banking.

Manual sync file Alternative to Google Drive: export/import a file by hand — no account or internet needed.

How to sync two devices:
  1. On Device A: tap "Export sync file" below and send yourself the file (email, cloud drive, USB, AirDrop, etc.)
  2. Open that file on Device B and tap "Sync from file"
  3. Device B now merges in anything new from Device A — nothing on Device B is deleted. Repeat in the other direction to bring Device A up to date too.

Merging matches records by ID and keeps whichever version was edited most recently on either device. Includes transactions, invoices, clients, and receipt photos, so larger files are normal.

Advanced: full restore instead of merge
